# Actividad 5 Analizar una finalidad secundaria

¿El hecho de que la organización ya tenga los datos significa automáticamente que puede utilizarlos para cualquier finalidad?
No, los datos se dieron para atender y facturar, para usarlos en promociones el cliente tiene que saberlo o aceptarlo

¿Qué preguntas debería realizar la organización antes de implementar este tratamiento?
- ¿El aviso de privacidad dice que se usan para promociones?
- ¿Se ocupa el consentimiento del cliente?
- ¿Se puede dar de baja?
- ¿Qué datos se ocupan de verdad?
- ¿Quién los va a ver?

¿Qué datos serían realmente necesarios?
El correo y si acaso la ciudad o el rango de edad

¿Necesitaría el área de marketing acceso directo a clientes?
No, solo a lo que ocupa y de los clientes que aceptaron

¿Qué controles técnicos podrían limitar la información entregada?
Una vista con correo, ciudad y rango de edad, un rol de marketing que solo vea esa vista y un campo para saber quién aceptó promociones
